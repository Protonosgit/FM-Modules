# FantasticMirror Widgets
Contains demo widgets for the FM Android project.

## Contribution
You can contribute your own modules but make sure they are acessible for all users, contain relevant instructions and do not harm any guidelines including but not limited to: Sexual content, paid content, malware, ads, violence, (cyber-)crime and harmful behavior.
All contributions are screened and shall not contain any of the above. All may be rejected or removed at any point for violation!

## Setup Clone
The app allows users to change their source repo but requires a similar structure to this one!
